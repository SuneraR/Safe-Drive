# Safe Drive 🚗💤

Safe Drive is a Flutter-based driver safety application designed to reduce road accidents caused by driver fatigue and drowsiness. The system combines real-time fatigue detection, sensor monitoring, camera-based analysis, and smart alerts to help drivers stay focused and safe while driving.

---

#  Features

##  Real-Time Fatigue Detection
- Detects driver drowsiness using live camera monitoring
- Monitors eye activity and facial behavior
- Calculates fatigue levels in real time
- Automatically triggers alerts when fatigue is detected

##  Smart Alert System
- Voice alerts
- Vibration alerts
- Local push notifications
- Continuous warning system for dangerous conditions

##  Ride Monitoring
- Start and stop ride tracking
- Background ride monitoring
- Real-time trip status handling
- Driving session management

##  Trip History & Analytics
- Stores previous ride data
- Tracks driving sessions
- Displays ride history and statistics
- Helps users review driving behavior

##  Firebase Integration
- Cloud-based user data synchronization
- Firebase Authentication
- Real-time database integration
- User profile management

##  User Settings & Personalization
- Adjustable alert preferences
- Sound and vibration controls
- Custom notification settings
- Personalized user experience

##  Authentication System
- User registration and login
- Secure authentication flow
- Persistent user sessions

#  How Fatigue Detection Works

The fatigue detection engine activates when the user starts a ride.

The system continuously analyzes:
- Driver facial activity
- Eye closure behavior
- Motion patterns
- Device sensor data

When unsafe fatigue patterns are detected, the application immediately alerts the driver using multiple warning methods.

#  Getting Started

## Prerequisites

Before running the project, make sure you have:

- Flutter SDK installed
- Android Studio or VS Code
- Firebase project configured
- Android device or emulator

---

## Installation

### Clone the repository

```bash
git clone https://github.com/SuneraR/Safe-Drive.git
```

### Navigate to the project directory

```bash
cd Safe-Drive
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
